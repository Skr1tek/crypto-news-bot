# Мониторинг Федресурса через бесплатный сайт

## Возможности

В Telegram доступны кнопка «Мониторинг Федресурса» и команды:

- `/fed` — меню, время последней проверки и ошибки.
- `/fedadd` — пошаговое добавление по ИНН; `/fedadd 7831000108` — сразу передать ИНН.
- `/fednow` — проверить публикации за текущий день по МСК.

После поиска бот показывает наименование компании и просит подтвердить добавление. Получатель по умолчанию — личный чат администратора. В списке компаний можно выбрать получателей из общего списка бота или снять компанию с мониторинга. Поддерживаются юридические лица с корректным 10-значным ИНН, до 20 компаний. Поддержка граждан и ИП с 12-значным ИНН не реализована.

Фоновая проверка выполняется примерно через 15 минут после предыдущей завершённой проверки. Она независима от новостного расписания 08:00/12:00 и лимита новостей. Считываются обе видимые вкладки публикаций компании, с пагинацией до конца текущего дня. Контрольный предел — 200 страниц на вкладку; при превышении проверка помечается неполной, а не успешной. Вложения не скачиваются. Отправляется доступный блок «Текст сообщения», а не ИИ-пересказ. Таблицы лотов вне этого блока и приложения в текстовую выдачу не включаются.

В каждом сообщении: компания на мониторинге, ИНН, наименование должника (если указано источником), номер публикации, дата/время по МСК, текст и прямая ссылка просмотра. Длинный текст делится на части с повтором реквизитов и ссылки. SQLite хранит подтверждения каждой части отдельно по компании/получателю/сообщению. После сбоя повторяются только недоставленные части. Как и для обычной рассылки, неопределённый сетевой результат между Telegram и фиксацией SQLite не позволяет гарантировать exactly-once.

Первое добавление включает все доступные сегодняшние публикации, не весь исторический архив. Последующие проверки отправляют новые. После перезапуска сохраняются компании, получатели и история. Если сервер был выключен и наступил следующий день, публикации предыдущего дня не догружаются — пользователь запросил только текущий день. Удаление/смена получателей не отменяет уже начатый рабочий запуск со снимком настроек.

## Бесплатный источник и ограничения

Используется исключительно публичный сайт fedresurs.ru, без платного API, аккаунта сервиса и ИИ. Обычный HTTP-запрос в проверочной среде вернул 403, но сайт открылся в обычном браузере: поиск по ИНН 7831000108 дал ТАВРИЧЕСКИЙ БАНК (АО), а 16.11.2026 на странице было сообщение №25536049 от 15:03:22 МСК с полным доступным текстом и ссылкой https://fedresurs.ru/bankruptmessages/9ef26ff1-cbb9-48cd-af74-7f79ee7aa01a .

Поэтому на сервере нужен браузерный движок Chromium/Playwright. Рабочий стол не требуется. Создаётся один временный браузер на задание, данные авторизации не копируются из личных браузеров. Дочернему Chromium не передаются токены из окружения бота. Sandbox включён; код не использует stealth, не решает CAPTCHA, не подменяет сессии и не обходит ограничения сайта.

Бесплатный сайт не даёт гарантии непрерывного автоматического доступа. Блокировка, CAPTCHA, изменение разметки, скрытый текст и невозможность загрузки страниц приводят к ошибке проверки. Это не трактуется как «новых сообщений нет». Администратор видит ошибку в меню и уведомление; одинаковые автоматические ошибки повторно уведомляются не чаще раза в 6 часов. Ручная проверка всегда сообщает результат. Работа источника именно с вашего VPS и запуск Linux sandbox должны быть проверены перед эксплуатацией.

Новые публикации — юридически значимые сведения источника; бот не делает самостоятельных правовых выводов и не отправляет их в OpenRouter. Текст публикаций в SQLite не сохраняется, только идентификаторы доставки; список компаний/ИНН и статус проверки сохраняются в той же защищённой базе бота.

## Установка на существующем Ubuntu-сервере

Сначала подключитесь по SSH. Эти команды выполняются на сервере, не в локальном PowerShell.

```bash
cd /opt/newsbot
git pull --ff-only origin feature/telegram-admin
.venv/bin/python -m pip install -r requirements-fedresurs.txt
PLAYWRIGHT_BROWSERS_PATH=/opt/newsbot/browsers .venv/bin/python -m playwright install --with-deps --no-shell chromium
```

Программа/системные зависимости берутся из официального пакета Playwright и репозиториев Ubuntu. Установка скачивает браузер и занимает дополнительное место; Chromium расходует память/CPU. На VPS с 2 ГБ RAM поддерживаются только последовательные проверки в одном браузере; фактическая нагрузка на вашем сервере ещё не измерена. Браузер следует обновлять вместе с версией Playwright, повторяя команду install.

В `/etc/newsbot.env` добавьте одну строку, не удаляя существующий токен, ID и путь базы:

```
PLAYWRIGHT_BROWSERS_PATH=/opt/newsbot/browsers
```

Оставьте файл доступным только root (`chmod 600 /etc/newsbot.env`). Браузерные файлы должны быть доступны пользователю newsbot на чтение/выполнение. Стандартная установка root с umask 022 это обеспечивает. Команда проверки не использует Telegram-токен и ничего не отправляет:

```bash
runuser -u newsbot -- env PLAYWRIGHT_BROWSERS_PATH=/opt/newsbot/browsers /opt/newsbot/.venv/bin/python /opt/newsbot/fedmonitor.py --check 7831000108
```

При успехе будут показаны найденная компания, текущий день МСК, номера/ссылки сообщений и длина прочитанного текста. Ноль сообщений является корректным только при успешно прочитанной странице. Если проверка не выполнена, не считайте мониторинг работающим; пришлите сообщение ошибки без секретов.

После успешной проверки:

```bash
systemctl restart newsbot
systemctl status newsbot --no-pager -l
```

В Telegram отправьте /start → Мониторинг Федресурса → Добавить лицо, либо `/fedadd 7831000108`. Подтвердите имя, затем при необходимости задайте каналы/группы через «Список компаний → Получатели» и нажмите «Проверить сегодня».

## Ошибки

- «Chromium не запущен»: проверьте установку браузера, PLAYWRIGHT_BROWSERS_PATH, права newsbot, свободную память и журналы. На Ubuntu 24.04 запуск sandbox может ограничиваться профилем AppArmor/параметрами user namespaces. Не отключайте защиту глобально; попросите администратора проверить профиль для конкретного установленного Chromium. Подробная настройка конкретной ОС не была проверена на вашем VPS.
- «HTTP 403»/«проверка человека»: автоматическое чтение сайта сейчас недоступно. Бесплатный режим не обходит эту проверку и не подключает платные сервисы. Откройте карточку вручную; для гарантированного мониторинга потребуется разрешённый стабильный источник.
- «Список/текст не прочитан»: возможно, сайт изменил разметку. Старые подтверждения доставки сохраняются, но ошибочная проверка не считается отсутствием публикаций.
- Для отключения модуля снимите все компании с мониторинга. Новостная рассылка работает без установки браузера и без requirements-fedresurs.txt.

## Проверки

`python -m unittest discover -s . -p 'test_*.py' -q`

Тесты используют временную SQLite, подменённый источник и Telegram, проверяют авторизацию, ИНН, подтверждение, дату МСК, пагинационные предпосылки, полные части текста, частичные сбои, несколько получателей и отсутствие ложного пустого успеха. Публичная страница и конкретная публикация проверены в обычном браузере. Отдельный автоматический Chromium в проверочной Windows-среде не запустился из-за ошибки загрузки chrome.dll: автоматическая проверка именно этим приложением на реальном сайте пока не подтверждена. Отправка реальных публикаций в Telegram в тестах не выполнялась.
